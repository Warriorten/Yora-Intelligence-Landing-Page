# 00 — Overview

## Website objectives

1. Establish Yora as a credible technology company delivering sophisticated supplement intelligence.
2. Explain the technology, proprietary two-score architecture, and competitive differentiation.
3. Demonstrate how enterprise clients can use Yora to improve platforms, product analysis, and decision-making.
4. Introduce the Yora Health consumer application (same intelligence engine), with App Store access when available.
5. Convert interested enterprise visitors into qualified demonstration requests.

## Overriding message

> **Intelligence Behind Better Supplement Decisions.**
>
> One intelligence platform. Multiple applications. Deeper insight into supplement quality.

## Site shape

Single scrolling website with these sections (can later become routes):

| # | Section | Nav label | Anchor ID |
|---|---------|-----------|-----------|
| 01 | Home (hero) | Home | `#home` |
| 02 | About Yora | About | `#about` |
| 03 | Yora Intelligence | Intelligence | `#intelligence` |
| 04 | Enterprise Solutions | Solutions | `#solutions` |
| 05 | Yora Health App | App | `#app` |
| 06 | Request a Demo | Request a Demo (CTA) | `#demo` |

Plus sticky header and footer.

## Tone

Sophisticated **enterprise technology** company — not a supplement retailer. Spacious layouts, strong typography, restrained palette, tasteful product visuals, subtle animations.

## Critical product rules (from brief)

- Do **not** imply existing enterprise clients or commercial results.
- Distinguish V4.0-supported capabilities vs planned ones.
- “Evidence unavailable” must **not** read as “failed verification.”
- Public examples must not expose proprietary rules, confidential data, or admin tools.
- App Store link: wire now, keep **Coming soon** until publicly available.
- Demo form: front-end only for this phase (validation + honeypot); production needs a secure backend later.
- Landing page visual system is the source of truth; Admin UI follows later (out of scope here).

## Out of scope (this project)

- Reskinning `~/Projects/Yora-Intelligence-Admin`
- Live form backend / lead CRM
- Activating real App Store URL
- Official brand assets swap (use placeholders derived from the example)
